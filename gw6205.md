# GW6205 12-Bit Addressable LED Chipset

## Overview

The GW6205 is a 12-bit-per-channel addressable RGB LED driver IC. It uses the same single-wire NRZ protocol as the WS2812 family but transmits 12 bits per color channel (4096 brightness levels) instead of 8 bits (256 levels). This results in 36 bits per pixel total.

## Electrical Specifications

| Parameter              | Value              | Notes                              |
|------------------------|--------------------|------------------------------------|
| Supply voltage (Vdd)   | 24V DC             | Requires resistor between PSU and VDD pin |
| Output port voltage    | Withstands 24V     | Single output port                 |
| Current per channel    | 18 mA              | Fixed constant current output      |
| Total current per LED  | 54 mA              | 3 channels x 18 mA                |
| Current accuracy       | ±1.5% between channels | ±3% between chips              |
| VDS (output dropout)   | 0.7V minimum       |                                    |
| Color depth            | 12 bits / channel  | 4096 levels per color (PWM)        |
| Bits per pixel         | 36                 | 12R + 12G + 12B                    |
| Color channels         | 3 (RGB)            | 3 constant current outputs         |
| PWM refresh rate       | Up to 1 KHz        |                                    |
| ESD protection         | > 8 KV             |                                    |
| Cascading              | Infinite            | In linear transmission when frame rate is not critical |
| Transmission distance  | > 10 meters         | Between any two points, no additional circuitry needed |
| Package                | Lead-free           | Environmentally friendly           |

## Internal Features

- Built-in power-on reset circuit
- Built-in signal shaping circuit
- Built-in Zener diode (requires external resistor between PSU and VDD)

## Protocol & Timing

| Parameter       | Value         | Notes                                  |
|-----------------|---------------|----------------------------------------|
| Data protocol   | NRZ           | Single-wire, same encoding as WS281x   |
| Data rate       | 800 kHz       | GW6205_400 variant runs at 400 kHz     |
| Bit period      | 1.25 us       | 1 / 800 kHz                            |
| Logic 1 (T1H)  | 750 ns high   |                                        |
| Logic 1 (T1L)  | 500 ns low    |                                        |
| Logic 0 (T0H)  | 250 ns high   |                                        |
| Logic 0 (T0L)  | 1000 ns low   |                                        |
| Reset time      | TBD           | Not confirmed — WS2812 uses >50 us     |

### Data Frame Structure

Each pixel requires 36 bits transmitted MSB-first (assumed, same as WS2812):

```
| 12-bit Green | 12-bit Red | 12-bit Blue |
|  G11 ... G0  | R11 ... R0 | B11 ... B0  |
```

> **Note**: Color order (GRB vs RGB) needs to be verified with actual hardware. WS2812 uses GRB; GW6205 may differ. The color order is configurable in software (RGB/GRB/RBG/GBR/BRG/BGR).

### Timing Diagram (1 pixel, RED = 0xFFF)

```
Data: Green=0x000, Red=0xFFF, Blue=0x000  →  #FF0000 equivalent
Hex payload: 0x000FFF000 (36 bits)
```

## Existing Library Support

| Library     | Status                                                                 |
|-------------|------------------------------------------------------------------------|
| FastLED     | Has `GW6205` and `GW6205_400` type definitions. **Broken on ESP32** — the clockless controller ignores the `XTRA0` template parameter needed for 12-bit output. Works on AVR/ARM platforms. |
| NeoPixelBus | No support. WLED depends on this library.                              |
| ESPHome     | No native support. Issues reported with flickering via FastLED backend.|

## Known Issues

- **FastLED ESP32**: The ESP32 clockless controller implementation is locked at 8 bits and ignores the `XTRA0` parameter that other platforms use to output extra zero bits for 12-bit channels. See [FastLED #746](https://github.com/FastLED/FastLED/issues/746).
- **WLED**: No support. Depends on NeoPixelBus which has no GW6205 driver. See [WLED #4246](https://github.com/Aircoookie/WLED/issues/4246).
- **ESPHome**: Flickering/stuttering reported. See [ESPHome #2792](https://github.com/esphome/issues/issues/2792).
